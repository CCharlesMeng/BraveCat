## 故事目标

Minho 在一次自主 Trip 中，想在清晨看见从湿地上空经过的候鸟。它先听见却看不见，
随后因雾主动改走较高的安全廊桥，终于在晨风打开雾层时看见鸟群。一根自然脱落的
小灰羽留在行囊扣带下，成为第四幕仍可看见的事件痕迹。

这是一个安全、自主、非任务式的小目标。Minho 不追逐鸟群，不接受指令，不救援、
修复或改变环境；Ambient Life 不指挥、帮助、奖励或围观 Minho。

## 四幕

### 第一幕：雾里有声音（建立）

- 时间：黎明前。
- 主要动作：Minho 背着唯一的橄榄绿行囊，在低处有顶栈道抬头寻找雾中的鸟影。
- 未完成目标：鸟鸣清楚，但两三只模糊鸟影很快消失，完整鸟群仍不可见。
- 空间方向：较高的观察廊桥轮廓从雾中显露；安全折返缓坡连接上下两层。
- Perch：宽阔干燥、远离栏外湿地的木石铺装面。
- Cat Framing：中景。
- Ambient Life：远处一名工作人员打开素面通风百叶，不看 Minho。
- Postcard：

  > 雾把声音送得很近，可我还没有看见它们。

### 第二幕：改走高处（经过）

- 时间：天色稍亮。
- 主要动作：Minho 判断低处视线仍被雾封住，转向并沿有护栏的干燥缓坡上行。
- 阻力与选择：留在低处继续等待，或前往更高、更开阔的位置；Minho 主动选择后者。
- 空间继承：第一幕低栈道缩小在后下方；第三幕观察窗出现在前上方。
- Perch：防滑、连续、有真实支撑和护栏的宽缓坡。
- Cat Framing：中远景。
- Ambient Life：一名普通访客从另一侧下行，彼此错开，不与 Minho 互动。
- Postcard：

  > 低处还是白茫茫的。我去高一点的地方等。

### 第三幕：风打开天空（抵达）

- 时间：日出时。
- 主要动作：Minho 在上层有顶观察廊桥安静 `gaze`；晨风打开雾层，完整候鸟群从
  初升太阳前方横越。
- 期待兑现：第一幕的声音和模糊鸟影在这里获得清楚答案。
- 事件痕迹：一根自然脱落的小灰羽飘落到 Minho 身旁的宽石台上。
- Perch：栏杆内侧、宽阔平整、有实体支撑且与缓坡相连的观察石台。
- Cat Framing：远景；天空和鸟群构成事件尺度，Minho 仍由银色轮廓与绿色行囊保持
  叙事主角地位。
- Ambient Life：两名很小的普通观察者位于不同纵深，各自看天空，不注意 Minho。
- Postcard：

  > 风把雾推开时，它们正好从太阳前面经过。

### 第四幕：羽毛留下（余韵）

- 时间：稍晚的清晨。
- 主要状态：鸟群和浓雾已经离开，Minho 在相连的有顶休息台自然 `sleep`。
- 事件痕迹：第三幕同一根小灰羽被晨风轻轻卡在唯一行囊的外侧棕褐扣带下；不表现
  Minho 拟人化收拾或包装。
- 空间继承：仍能看见第三幕观察窗、栏杆、湿地轮廓和缩小的低层栈道。
- Perch：靠实体矮墙、有完整腿部支撑、宽而平的干燥木石长凳。
- Cat Framing：近景，环境仍保留足够比例。
- Ambient Life：一名工作人员沿远处缓坡离开，不看 Minho。
- Postcard：

  > 它们已经飞远了。有一根羽毛，把清晨留了下来。

## Album 尾页

> 鸟鸣，是晨光的回响。它在雾里多等了一会儿，天空便从眼前经过。

第一句化用 Rabindranath Tagore, *Stray Birds* 第 245 则：
“The bird-song is the echo of the morning light back from the earth.”

## 连续性锁

- 始终是批准的银渐层 Minho：蓝绿色眼睛、紧凑结实的自然猫体型、柔和环纹粗尾、
  无配饰。
- 每格恰好一只 Minho、恰好一只行囊。
- 行囊始终是同一只小型橄榄绿帆布行囊：棕褐色翻盖、两条棕褐色扣带、顶部固定
  一卷米色薄毯；轮廓、结构、颜色和尺度不变，绝不复制。
- 前三幕行囊由 Minho 自然背负；第四幕放在睡着的 Minho 身旁。
- 第三、四幕恰好是同一根小灰羽；第一、二幕不提前出现羽毛。
- 始终是同一处原创虚构湿地设施：深色木栈道、浅色石墩、普通金属护栏、折返缓坡、
  上层有顶观察廊桥、宽观察窗和有支撑的休息长凳。
- 可步行路线清楚：低层有顶栈道 → 折返缓坡 → 上层观察廊桥 → 相邻有顶休息台。
- 相邻两幕至少保留上一幕一个清楚可辨的空间锚点。
- 时间线可信：蓝灰黎明前 → 珍珠灰早晨 → 桃金日出 → 淡金稍晚清晨。

1. Minho 身份板：只锁定银渐层毛色、蓝绿色眼睛、体型、脸、尾巴和温和气质；
   忽略身份板内文字与排版。
2. `walk`：只锁定第一、二幕自然四足行走的猫科解剖和承重。
3. `gaze`：只锁定第三幕自然抬头凝望的猫科解剖和承重。
4. `sleep`：只锁定第四幕自然蜷卧睡眠的猫科解剖和承重。
5. 既有 Scene 参考：只锁定橄榄绿行囊及低保真水彩彩铅语言；绝不继承或复用其中的
   山地车站、列车、观测站、山脉、人物、镜位、构图、灯光或故事。
