## 故事目标

Minho 在一次自主 Trip 中，想从曜帆谷东侧入口穿过中央窄桥，抵达西侧果园露台。
一只奶油色小山羊从相反方向走来；两位旅者在桥中央相遇。Minho 主动使用半圆错身
台让出通路，小山羊通过后停步回望，等 Minho 也完成过桥。它们以自然动物行为互相
示意：小山羊轻轻点头并放松耳位，Minho 抬头慢眨回应，随后各自继续相反方向的旅程。

这是安全、自主、非任务式的小目标。Minho 不接受指令，不救援、修复或改变环境；
小山羊不是奖励或向导，Ambient Life 不指挥、帮助、奖励、围观或庆祝 Minho。

## 四幕

### 第一幕：两条路正在靠近（建立）

- 时间：晴朗晚晨。
- 主要动作：Minho 背着唯一行囊，从东侧宽入口台自然 `walk` 进入山谷；小山羊从
  西侧果园露台向东走来。
- 未完成目标：两者仍相隔很远，但路线明确汇入同一座窄石桥，Minho 尚未抵达西侧。
- 空间方向：前景东入口、中央窄桥与半圆错身台、远处西露台形成一条连续路线。
- Perch：干燥、粗面、防滑、有实体支撑的宽石入口台。
- Cat Framing：中远景；Minho 清楚可辨，谷地规模和路线仍占主要画幅。
- Ambient Life：极远处两名维护者在独立服务道检查普通锚索；不看 Minho。
- Postcard：

  > 我要去山谷那边，它正从那边走来。

### 第二幕：桥中央相遇（经过与选择）

- 时间：正午前。
- 主要动作：Minho 与小山羊从桥两端接近后同时停下；桥面安全但普通路段不足以
  舒适错身。Minho 主动退入桥侧半圆错身台，自然 `sit` 并侧开身体，留下完整通路。
- 阻力与选择：继续挤过对方，或使用桥体的错身结构礼让；Minho 选择后者。
- 场景互动：半圆错身台不是装饰，而是 Minho 实际进入并使用的叙事空间。
- 空间继承：后方保留第一幕东入口，前方看见第三幕两端宽平台和完整桥面。
- Perch：与桥面一体、有实体支撑和低护缘的半圆石质错身台。
- Cat Framing：中景；Minho、小山羊、窄桥和错身台同时清楚可读。
- Ambient Life：一辆普通果篮维护车停在远处隔离服务区；不关注两只动物。
- Postcard：

  > 桥上有点窄，我先把中间这一步让开。

### 第三幕：它也停了一步（抵达与互相示意）

- 时间：澄澈正午。
- 主要动作：小山羊已经通过并站在东侧宽平台；Minho 也已走完桥，站到西侧宽平台。
  两者隔着不长的桥回头互相示意：小山羊以自然、克制的轻点头和放松耳位回应；
  Minho 抬头并以一次自然慢眨回应。禁止人类式挥手、鞠躬、敬礼或夸张表情。
- 期待兑现：Minho 抵达西侧，小山羊抵达东侧；双方通过同一处窄桥且互不受阻。
- 场景变化：数百面巨型遮阳风帆在高处同步展开，宽大的风影越过多层果园、桥面、
  水渠与服务道，但不遮没两位主角。
- Perch：东西两端均为与桥相连、有低护缘的宽石平台。
- Cat Framing：中远景；距离足以读出抬头、慢眨、轻点头和放松耳位，同时保留
  壮阔谷地。
- Ambient Life：极小的维护者在不同纵深继续各自工作；不注意动物互动。
- Postcard：

  > 它等我把桥走完，又轻轻点了一下头。

### 第四幕：去往相反的方向（安静余韵）

- 时间：金色午后。
- 主要状态：Minho 已在西侧果园露台停步 `gaze`，小山羊继续走向东侧高台；两者
  不再停留或跟随。下一阵风影掠过已经空出的桥和错身台。
- 改变与余韵：它们没有成为固定旅伴，也没有留下纪念物；同一座桥从冲突空间变为
  两段旅程都已安全通过的空桥。
- 空间继承：西露台、窄桥、半圆错身台、东入口和两条离开路线全部保留。
- Perch：西侧低墙内、宽阔干燥并有真实承重的果园露台。
- Cat Framing：Minho 中景；小山羊是远处但可辨认的第二角色。
- Ambient Life：维护人员已经沿服务道远离，谷地恢复普通节奏。
- Postcard：

  > 我们去了相反的方向，也都记得在桥上停过一步。

## Album 尾页

> 它们没有成为同路人，只在窄桥上各让了一步。于是两段不同方向的旅程，都没有停下。

本故事不使用文学引语。

## 连续性锁

- 始终是批准的银渐层 Minho：蓝绿色眼睛、紧凑结实的自然猫体型、柔和环纹粗尾、
  无配饰。
- 每格恰好一只 Minho、恰好一个行囊、恰好同一只小山羊；不得复制任何角色。
- 行囊四幕始终自然背负在 Minho 背上：同一只小型橄榄绿帆布行囊，棕褐色翻盖、
  两条棕褐色扣带、顶部固定一卷米色薄毯；轮廓、结构、颜色和尺度不变。
- 小山羊始终是奶油色短毛、浅棕耳尖、短小自然角芽、细长但可信的幼年体型；
  无衣服、项圈、行囊或其他配饰。
- 稳定地点锚点：多层果园露台、象牙白/浅金/淡橙巨型遮阳风帆、普通高杆与锚索、
  石拱支架、浅灌溉渠、东西入口平台、中央窄石桥、桥侧半圆错身台、独立服务道。
- 可步行路线：东侧宽入口台 → 中央窄桥东端 → 半圆错身台 → 窄桥西端 → 西侧果园露台。
- 时间与光线：明亮晚晨 → 正午前强光 → 澄澈正午 → 金色午后；全程晴朗、干燥。
- 每一幕至少继承上一幕两个空间锚点，同时改变人物距离、位置、动作与风影状态。
- 所有视角接近猫的高度。猫、山羊、行囊、桥、帆架、人物、车辆均保持可信比例、
  支撑、接触面和接触阴影。

- 不出现雨、雾、雪、夜景、热气球、船队、风筝节、游行、国旗、徽章、品牌、
  可读导视、文字或伪文字。
- 不复现现实果园、场馆、桥梁、艺术装置、影视布景或知名镜头；曜帆谷的空间关系、
  构图与功能设施从本故事的路线和物理需求独立设计。
- 不出现追逐、危险跳跃、坠落、救援、任务、喂食、赠礼、庆祝、奖励或纪念物。
- 两只动物不握手、挥手、鞠躬、敬礼、拥抱、直立行走或做任何人类式礼仪动作。
- 环境人物不围观、帮助、指挥或与动物互动。

## 最近邻情节碰撞审计

最接近的既有故事是 `frostwell-pawprint-circle`，因为两者都包含路径判断和阳光变化。

- 既有故事的无名词骨架：选择一处空白表面 → 放弃危险捷径 → 用自身移动创造图案
  → 看着短暂痕迹消退。
- 新故事的无名词骨架：两位旅者沿相反路线进入共享通道 → 通行空间发生冲突 →
  一方使用错身结构主动礼让，另一方停步回应 → 双方完成各自旅程并继续相反方向。
- 实质区别：愿望由创造个人痕迹变为完成相向通行；第二幕由自我避险变为关系判断；
  第三幕由单方面创造图案变为双方完成通行后的互相示意；第四幕由物理痕迹消融变为
  两段旅程恢复、共享通道重新空出。

与 `reed-mist-morning-flight` 也不存在“追随移动目标 → 改路抵达 → 获取残片”的重复：
Minho 不追逐小山羊，小山羊与 Minho 走向相反方向，第三幕没有获取物，第四幕不保留
任何目标残片。
