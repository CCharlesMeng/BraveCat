## 已确认方向

- 第一幕以浅桃金朝阳、薄海雾、暖色水面反光、多层船只和开工活动表现欣欣向荣的早晨。
- 第二幕切入宽阔公共候船厅，从低位室内广角看雨窗、门洞、仓廊屋顶和港池，明显区别于第一幕外景。
- 第二幕保留三只不同毛色、无行囊的环境幼猫，Minho 仍是连续四幕的主角。
- 第三幕由普通渔民在安全平台上赠送一条处理好的小鱼，不出现围观、喂食或庆功。
- 第四幕以 Minho 在受支撑长凳上抱着唯一小鱼干睡觉收束，唯一行囊放在身旁。
- 四幕持续使用同一港口、船只、仓廊、灯具、潮窗和水道材质语言。
