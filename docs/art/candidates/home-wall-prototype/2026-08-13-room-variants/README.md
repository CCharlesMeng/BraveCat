# Home 房间透视原型 · 三方案

日期：2026-08-13。状态：**结构控制图，未生成水彩，不得进入 `public/`**。

三套方案都是正常矩形房间，只改变相机朝向、两面墙的占比以及陈列所在平面。
所有竖线保持竖直；同一墙面的横边共享灭点；水平线上下的斜率符号相反。

## A · 后墙共享型

文件：
`../2026-08-13-right-recede/perspective-control--standard-rectangular-room--v06-wide-right-wall.png`

- 后墙右灭点 `x=3000`，右墙左灭点 `x=-350`，内角 `x=930`。
- 窗户和六张明信片在同一面后墙。
- 右墙占画宽 `22.5%`，完整容纳纪念品柜。
- 窗台观察、抓柱、食盆和地毯沿用当前 Home 的左右关系。
- 优点：最接近当前产品构图，信息均衡，改造范围最小。

## B · 宽右墙画廊型

文件：`room-prototype--b-wide-right-gallery--v01.png`

- 后墙右灭点 `x=2600`，右墙左灭点 `x=-250`，内角 `x=760`。
- 大窗独占后墙；六张明信片和低柜都在宽右墙。
- 右墙上的卡片越靠画面右侧越接近镜头，因此必须更大，不能“右列收小”。
- 猫仍可在窗边观察、抓柱活动、地毯睡玩、墙角进食。
- 优点：陈列最像真实家庭画廊，窗景和回忆互不争抢。

## C · 中央记忆墙型

文件：`room-prototype--c-central-memory-wall--v01.png`

- 后墙左灭点 `x=-1400`，左墙右灭点 `x=2400`，内角 `x=300`。
- 窗户移到左侧墙；六张明信片和纪念品柜成为后墙中心。
- 窗边保留抓柱与观察位；地毯占据中央前景，食盆位于两区之间。
- 优点：旅行回忆成为首屏视觉中心，陈列容量最清楚。
- 代价：与当前“窗景主视觉”差异最大，需要重新安排猫在窗台的姿势锚点。

## 共同生活与陈列门槛

- 六张明信片必须位于单一真实墙面，轨道、边框和卡面共享投影。
- 纪念品柜必须贴合其承载墙面的灭点方向。
- 保留窗台观察、抓柱、食盆、中央地毯睡眠/玩耍四类猫活动位置。
- 陈列不得侵入猫活动包络；地毯与进食区之间保留可读动线。
- 选定结构前不生成水彩，避免用美术细节掩盖错误户型。
