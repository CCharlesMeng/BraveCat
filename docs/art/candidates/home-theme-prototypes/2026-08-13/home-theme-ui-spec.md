# Home Theme 样式 UI 提案

状态：静态设计。此文档不授权运行时代码实现。

## 推荐方向

采用 **A「底部主题抽屉」+ B「点物换件」** 的组合。

- A 负责浏览和套用完整 Home Theme preset。
- A 的“部件”页负责按类别浏览兼容部件。
- 选中具体类别后进入 B，在真实房间中直接确认替换对象与视觉结果。
- C「全屏主题册」保留为主题数量明显增多后的扩展，不作为首版主流程。

这样既能一键换整套风格，也不会把窗框、相框、猫爬架、碗、柜子等独立
替换压缩成复杂的设置表单。

## 入口

- Home 标题区提供一个低权重“家主题”入口，与小鱼干数量分离。
- 不增加第四个底部主导航；行囊、小铺、相册仍是主要游戏循环。
- 入口只在猫在家或离家空房时改变文案，不因当前猫不同而改变选择。

## 主题抽屉

抽屉高度约为移动端画面的 42–48%，上方继续显示真实 Home：

- 标题：`家主题`
- 一级切换：`主题` / `部件`
- 主题卡：预览、名称、是否正在使用
- 主操作：`使用这个主题`
- 关闭：未确认的预览全部回滚

点选主题卡时立即预览整个房间，但不写入存档；只有点击主操作后才保存。

## 部件浏览

类别顺序：

1. 窗框
2. 陈列
3. 猫爬架
4. 碗
5. 柜子
6. 地毯
7. 墙面

只显示当前 HomeForm 与 socket 兼容的选项。没有兼容选项的类别直接隐藏，
不展示禁用空状态。

## 点物换件模式

- 房间保持全尺寸，非当前对象不加蒙层。
- 可替换对象使用细描边和一个小圆点，不显示开发态边界框。
- 点击对象后，底部只显示该 socket 的兼容部件。
- 操作：`复原`、左右浏览、`完成`。
- 选择即时预览；`完成`保存，关闭或返回则恢复进入该模式前的值。
- 猫活动区域不能被面板长期遮挡；面板最高不超过画面的 30%。

## 主题册

C 方向仅在主题数量超过约 6 套时启用：

- 用于浏览完整预览、主题故事和协调色板。
- 不承担逐物件编辑。
- 从主题册选择 preset 后仍回到 Home 进行实景预览和确认。

## 视觉语言

- 延续现有米白纸张、鼠尾草绿、浅木色和细褐线。
- 选中状态只使用一层绿色描边与小勾，不使用高饱和色。
- 不使用玻璃拟态、渐变、大面积阴影或“施工/装修”图标。
- 主题缩略图保持相同相机比例；不得为了卡片美观单独改裁切。
- 部件缩略图使用透明底或统一纸面底，必须保留真实朝向。

## 文案

- `家主题`：整体 preset。
- `部件`：可单独替换的 Home Part。
- `使用这个主题`：确认整体 preset。
- `完成`：确认本轮单件调整。
- `复原`：恢复进入编辑前的选择。

避免：`装修`、`家具仓库`、`摆放`、`皮肤背包`。

## 首版范围

- 支持 A、B、F 三个 HomeForm 的主题预览入口。
- 先开放 `陈列` 与 `猫爬架` 两类部件切换，验证 socket 交互。
- 其他类别可显示在设计稿中，但首版未有两个真实 adapter 前不进入运行时。
- 不加入价格、解锁、购买或拖拽摆放。
