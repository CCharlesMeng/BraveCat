# 小猫用品美术方向

状态：新方向设计提案。小猫用品必须让猫产生可见活动，不承担房间装修。

## 首批四件

### `scratch-basic` · 双层抓柱

来源：现有 A/B/F 抓柱造型。

- 行为：`gaze`、`play`、`stretch`。
- 物理事实：完整底座、主立柱、两个可承重点和一个玩耍目标。
- 主题适配：
  - A：浅木 + 鼠尾草织物。
  - B：胡桃木 + 奶油藤编。
  - F：白橡 + 烟蓝毡。
- 不变识别：上下双平台、单根主柱、紧凑占地。

### `feed-ceramic-pair` · 陶瓷双碗

来源：现有 A/B/F 食盆造型。

- 行为：`eat`、`sniff`。
- 物理事实：两个碗中心、单一承托垫、猫进食落脚点。
- 主题适配：
  - A：斑点青瓷 + 鼠尾草垫。
  - B：哑光沙陶 + 陶土垫。
  - F：蓝白陶瓷 + 烟蓝垫。
- 动态食物和水另层；碗口是否需要 foreground 由叠层 QA 决定。

### `rest-cloud-bed` · 云朵猫窝

新设计。一个低矮、柔软、边缘像云团但不过度拟物的椭圆猫窝。

- 行为：`sleep`、`stretch`、`greet`。
- 物理事实：中央睡眠面、柔软前沿遮挡、两个承重点和进出方向。
- 主题适配：
  - A：鼠尾草亚麻外圈、燕麦色内垫。
  - B：奶油织物外圈、低饱和陶土滚边。
  - F：烟蓝毡外圈、月白内垫。
- 不变识别：三瓣柔和云边、椭圆开口、低前沿。
- 禁止：皇冠床、蕾丝公主床、成人沙发缩小版、家具腿。

### `play-soft-tunnel` · 软布隧道

新设计。一段可折叠的短软隧道，侧面有一个窥视孔和单个悬挂布球。

- 行为：`play`、`reach`、`sniff`、`greet`。
- 物理事实：入口、出口、侧孔、内部猫路径、悬挂目标和不滚动底面。
- 主题适配：
  - A：鼠尾草布面、浅木色加固圈。
  - B：燕麦布面、胡桃色滚边、陶土玩具球。
  - F：烟蓝布面、月白加固圈、深靛蓝玩具球。
- 不变识别：短圆筒、一个侧孔、一个悬挂球。
- 禁止：彩虹塑料、游乐园管道、复杂迷宫、遮住整只猫的黑洞。

## 后续候选

- `play-ball-track`：低矮球轨，支持 `reach`、`play`。
- `play-puzzle-feeder`：益智喂食盘，支持 `sniff`、`reach`。
- `rest-cardboard-hideout`：纸箱窝，支持 `sleep`、`greet`。
- `scratch-flat-mat`：地面磨爪垫，支持 `stretch`、`scratch`。

后续用品只有在首批四件与真实猫 Pose 验收通过后才扩展。

## 用品选择视觉

- 用品卡片主图优先展示猫正在使用，而不是静物商品照。
- 所有使用效果必须引用项目当前实际猫 Portrait；默认验证猫是 Minho。
  `aigc-portrait-spike` 等未批准候选不得代替用户的猫。
- 卡片只写用品名和活动动词，例如“钻进去玩”“在这里睡一会儿”。
- 不显示家具尺寸、兼容主题或装修风格；主题适配由 resolver 隐藏。
- 同一用品的 A/B/F 外观可在详情页作为小色板预览，不拆成三个库存物品。

## 资产交付

每个用品 × 每个主题 adapter 至少交付：

1. `base` 透明图层。
2. 按需 `foregroundOcclusion`。
3. `supportSurface`、猫落脚点、互动目标和进出方向 QA。
4. 每个支持 Pose 的合成截图。
5. 三主题并排识别板，证明它们是同一用品而非三个不同家具。

不交付自由摆放缩略图、拖拽边界或家具兼容错误状态。
