# 可行性结论：照片 → 风格化形象 → 姿势一致套图

日期：2026-08-13。样张与评估细节见同目录 [`README.md`](./README.md)。

## 结论：有条件可行

「用户上传一张猫照片 → 风格化成游戏画风 → 输出 10 个姿势一致的 Portrait 套图」在当前（2026-08）技术条件下可以做成生产功能。理由：

1. **核心链路已被样张验证。** 以「照片 + 现役姿势 png」双参考图 + 特征文字锁定的提示词结构，四个姿势（sit/sleep/walk/eat）全部产出画风匹配、物理正确、角色可辨识一致的候选图，规格与现役 1024×1024 资产兼容。
2. **目标平台能力对口。** 百炼万相 2.7（`wan2.7-image-pro` / `wan2.7-image`）原生支持多图参考（最多 9 张输入）、图像编辑、**角色一致性组图生成（单次最多 12 张连续一致图）**，与「10 姿势套图」需求直接对口；编辑/组图场景最高 2K 输出。
3. **成本在付费功能毛利空间内。** 单用户单形象全程约 2.5–7.5 元（见下文），对一次性付费点足够。

「有条件」的三个条件：

- **条件 A：** 本 spike 的生成器是替身，万相 2.7 的角色一致性实际强度必须用真实 API 复刻本 spike 打样验证（用同一张照片替身跑 10 姿势组图），这是上线前的第一优先事项。
- **条件 B：** 花色漂移（饱和度、白/橘分界线）在样张中已实际出现，玳瑁/重点色/奇特斑块猫预计更严重。必须配自动 QA + 失败重试 + 用户确认页，不能裸奔。
- **条件 C：** 抠图不能用阈值法（白毛贴白底边缘 38%–66% 像素接近纯白），必须用分割模型。

## 生产管线建议

```
上传照片
  → ① 预处理：内容安全审核、猫主体检测、裁切、方向矫正
  → ② 特征提取（qwen-vl 描述花色分块/眼色/体型，生成特征锁定文字）
  → ③ 生成：wan2.7-image-pro 多图参考 + 角色一致性组图
       输入 = 用户照片 + 逐姿势现役风格锚图；输出 2K、中性浅底
  → ④ 抠图：SegmentCommonImage（VIAPI 通用分割，直接返回四通道 PNG）
  → ⑤ 规格归一化：降采样 1024×1024、基线重锚定到 support-contact-bottom-center
  → ⑥ 自动 QA（不合格姿势单独重试，上限 2 次）
  → ⑦ 用户确认页（「这是我的猫吗」）→ 入库
```

要点：

- **③ 生成**：保留本 spike 验证过的「双参考图 + 特征文字」结构；底色从纯白改为中性浅灰绿（如 #E8EDE8），避免浅色猫同色贴边，抠图后不留色边。10 姿势可先试单次组图（`n≤12`，一致性最好、最便宜），组图内个别姿势不合格再逐姿势编辑重试。
- **④ 抠图**：VIAPI 通用分割输入限制最长边 ≤1999px，2K（2048px）输出需先缩到 1999px 以内或改用通用高清分割；自托管 rembg/BiRefNet 可作为零边际成本备选。
- **⑤ 归一化**：样张实测底部留白 70–248px 不等，锚点约定必须由后处理保证（按 alpha 包围盒裁切 + 统一底距重排版），不能指望模型出齐。

### 自动 QA 检查项（⑥）

| 检查项 | 方法 | 卡点 |
| --- | --- | --- |
| 单主体 | 检测框计数 | 有且仅有一只猫 |
| 姿势正确 | 姿势分类 / 关键点 | 落脚面与承重点符合 `portraitPoseVocabulary` |
| 目标物 | 视觉模型问答 | eat/play 必须含 portrait-contained 目标；gaze/sniff/reach/greet 不得把 scene-provided 目标烘进图内 |
| 花色一致 | 与基准 sit 图比较前景色直方图 + 色块拓扑 | 平均色距离与分块结构在阈值内（样张实测漂移 ΔRGB≈(7,18,32)，阈值需打样标定） |
| alpha 质量 | 连通域 + 边缘扫描 | 无孤岛、无半透明噪点、无同色光晕 |
| 规格 | 尺寸/锚点断言 | 1024×1024、水平居中、底距公差内 |

## 单次生成成本估算（10 姿势 / 用户 / 形象）

按 2026-08 百炼华北 2（北京）刊例价：

| 项目 | 单价 | 用量（含 ~40% QA 重试） | 小计 |
| --- | --- | --- | --- |
| 生成 · 旗舰 `wan2.7-image-pro` | 0.5 元/张 | 14 张 | 7.0 元 |
| 生成 · 标准 `wan2.7-image`（成本优先备选） | ≈0.21 元/张 | 14 张 | ≈2.9 元 |
| 抠图 · VIAPI 通用分割 | 0.002 元/次 | 14 次 | ≈0.03 元 |
| QA · qwen-vl 视觉校验 | ≈0.01–0.05 元/图 | 14 图 | ≈0.1–0.7 元 |

**合计：标准版约 3 元 / 旗舰版约 7–8 元每用户每形象。** 计费均按成功出图张数，失败不扣费；新账号有 50 张免费额度（90 天）可覆盖打样。若该功能定价 12–30 元/次，毛利空间充足；标准版与旗舰版的画质差值得在条件 A 打样时一并对比。

## 剩余风险

1. **万相真实一致性未打样**（条件 A）。文档能力与替身生成器都指向可行，但「同一只猫 10 姿势」的真实合格率未知；若组图模式一致性不足，退化方案是逐姿势图像编辑（成本不变，一致性靠特征文字 + QA 兜底）。
2. **奇特花色长尾**。玳瑁、重点色、无固定斑块的猫最难锁定；预计合格率下降、重试成本上升。缓解：QA 重试上限 + 用户确认页 + 客服人工重生成兜底。
3. **用户照片质量长尾**。模糊、遮挡、多猫合影、非猫照片。缓解：①️ 预处理硬卡 + 上传引导文案。
4. **分割 API 分辨率限制**（1999px）与 2K 输出的冲突，属工程细节但容易踩坑。
5. **内容安全与合规**。上传含人脸/敏感内容需审核拦截；生成结果也需过机审。
6. **价格波动**。万相刊例价近两年快速迭代，上线前按控制台实时价复核成本模型。
