# Home Background Candidates v1

**NON-SHIPPING / CANDIDATE-ONLY.** Every file in this directory is an art-review artifact. Nothing here is approved for production, runtime use, or app integration.

Phase 1 contains two text-free home-background directions, one comparison sheet, and machine-readable composition zones. Visual selection is required before any later phase.

## Files

- `home-background--candidate-a--non-shipping-v01.png` — NON-SHIPPING straight-on morning-room candidate.
- `home-background--candidate-b--non-shipping-v01.png` — NON-SHIPPING oblique overcast-room candidate.
- `contact-sheet--home-backgrounds--non-shipping-v01.png` — NON-SHIPPING art comparison sheet.
- `composition-metadata.v1.json` — NON-SHIPPING candidate composition metadata.
- `README.md` — this NON-SHIPPING manifest.

All PNGs are 1200×1600, 8-bit RGB, and carry an sRGB profile. Candidate sources contain no cat, copy, controls, labels, signatures, or watermarks. The JSON defines top-left-origin pixel coordinates, bounds as `x`/`y`/`width`/`height`, and `catAnchor` as the future overlay's bottom-center point.

No production files were changed and no app integration was performed.
