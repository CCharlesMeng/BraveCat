# 咪游记 中国大陆商业发布合规行动清单（2026-08）

> 调研日期：2026-08-13。本文基于当日可核实的官方与一手来源整理，**不构成法律意见**；标注「⚠️ 未核实 / 来源冲突」的条目请以官方渠道实时确认。
>
> 产品背景：旅行青蛙式轻量陪伴游戏（Svelte Web PWA），四端商业化（iOS / Android / 微信小程序 / Web）。变现 = AI 猫咪形象生成按次付费（阿里云百炼 / 通义万相）+ 轻度虚拟货币礼包 IAP。后端自建、托管阿里云。用户上传自家猫照片用于 AI 生成。一人开发者。

---

## 0. 一页结论

1. **商业变现必须注册市场主体**：微信支付 / 小程序虚拟支付不对「个人主体」开放；ICP 单位备案、深度合成类目也要求非个人主体。最轻路径是**个体工商户**（3–7 个工作日、近乎零成本），但若走游戏版号则**必须内资有限公司**。
2. **产品定性是最大分叉点**：被认定为「游戏」→ 国内任何收费（内购/付费下载）都需要**版号**（个人无法申请，需公司 + 出版单位合作，4–8 个月）。以「AI 宠物形象生成 + 陪伴记录」非游戏定性 → 可绕开版号，但存在类目被驳回/重新认定的风险。
3. **AIGC 合规三件套 2025-09-01 起已全部强制**：① 调用已备案大模型（通义万相已备案）→ 向属地网信办做「登记」（非完整备案）；② 生成图片必须加显式 + 隐式标识（GB 45438-2025 强制国标）；③ 作为「服务提供者」自担内容审核、用户协议、投诉处置义务——阿里云只是「技术支持者」，责任不转移。
4. **用户上传照片按敏感个人信息对待**：照片可能含人脸（生物识别信息）→ PIPL 要求单独同意 + 事前个人信息保护影响评估（报告保存 3 年）。

## 1. 行动清单（按依赖顺序排列）

依赖关系总览：

```
A1 软著 ─────────────────┐
A2 注册主体 ──┬─ A4 ICP备案(网站) ──┬─ A7 App备案+小程序备案 ── 上架
              ├─ A5 小程序注册+认证 ─┼─ A8 微信支付+虚拟支付
              ├─ A6 百炼企业账号 ────┼─ A9 深度合成类目
              │                      └─ A10 大模型登记(属地网信办)
              └─ (版号路线) A15 公司 → ICP许可证 → 出版社 → 版号 → 防沉迷接入
A11–A14 工程与制度项（标识/审核/隐私/未成年人）：与上并行，上线前完成
```

### 第 1 批：立即启动（无前置依赖）

#### A1. 计算机软件著作权登记

- **要做什么**：为「咪游记」客户端 + 后端登记软著。软著是国内安卓商店上架、微信小游戏（含免费）提审、以及未来版号申请的必备材料。⚠️ 注意：若未来要申请版号，**软著权利人必须与版号申请公司一致**，且有第三方称 2025 年起软著名称须与游戏名完全一致（来源为代办机构，未见官方原文）——建议软著直接登记在拟设立的主体名下，或先个人登记、设立公司后办转让/重新登记。
- **去哪办**：中国版权保护中心线上系统 <https://register.ccopyright.com.cn>（全程无纸化）。
- **时长与费用**：官费 0 元（登记费已停征）；普通通道约 60–75 个工作日（实际 2–3 个月）。代理加急 3–10 个工作日，市场价约 500–2000 元（非官方渠道）。部分安卓渠道（小米等）接受「电子版权认证」替代纸质软著用于上架。
- **依赖前项**：无（材料：申请表 + 源代码前后各 30 页 + 说明文档 ≥10 页 + 身份证明）。
- **来源**：[计算机软件著作权登记办法（官方 PDF）](https://www.ciie.org/resource/upload/zbh/202407/0850005.pdf)；[中国版权保护中心登记入口](https://register.ccopyright.com.cn)；时长/费用参考第三方汇总 [壹点壹线](https://www.icp-1.com/zixun/16786.html)（⚠️ 非官方）。

#### A2. 注册市场主体（决策点 D1，见第 2 节）

- **要做什么**：注册**个体工商户**（轻路径）或**一人有限公司**（版号路径必需）。经营范围建议包含「软件开发、信息技术服务、互联网信息服务」等；若拟走版号，公司经营范围需含「网络游戏开发/运营」且为纯内资。
- **去哪办**：所在地政务服务网 / 市场监督管理局，多数地区全程网办。
- **时长与费用**：3–7 个工作日；登记免费，刻章约 200–500 元，如需地址托管约 1500–3500 元/年。个体户可核定征收、年应纳税所得 200 万以内个税减半（政策延续至 2027 年底）；公司需建账报税（代账约 2000–4000 元/年）+ 分红双重征税（小微企业所得税优惠下实际税负 2.5%–5%）。
- **依赖前项**：无。
- **来源**：对比与费用为第三方汇总（⚠️ 非官方，各地有差异）：[01MVP 个体户 vs 公司](https://01mvp.com/docs/guide/launch/company-registration)、[立华星财务](https://www.360lihua.com/c36269.html)。

#### A3. Apple Developer Program 注册

- **要做什么**：注册苹果开发者账号。**个人账号（¥688/年）即可上架付费 App 和内购**，无需公司资质；但 App Store 会以你的法定姓名作为开发者名称展示。⚠️ 关键限制：若走中国区「游戏」类目，必须填写版号，且**版号主体与账号主体不一致时需授权书、而个人开发者账号不能接受版号授权**（来源为第三方实战总结，苹果官方仅确认「中国大陆供应情况」为必填合规项）——即中国区游戏路线实际需要公司开发者账号。
- **去哪办**：Apple Developer App（中国大陆个人可直接在 App 内注册、人脸验证）或 developer.apple.com。公司账号需先申请 D-U-N-S 编码（免费，3–5 个工作日）。
- **时长与费用**：1–2 个工作日审核；个人/公司 Apple Developer Program 均为 99 美元/年（大陆 ¥688/年）。
- **依赖前项**：无（公司账号依赖 A2 的公司主体）。
- **来源**：[Apple 官方：注册会员资格](https://developer.apple.com/cn/help/account/membership/program-enrollment/)；[Apple 官方：中国大陆 App 内注册](https://developer.apple.com/cn/help/account/membership/enrolling-in-the-app/)；[Apple 官方：中国大陆供应情况为必填项](https://developer.apple.com/cn/help/app-store-connect/reference/app-information/required-localizable-and-editable-properties/)；个人账号不能被版号授权：[腾讯新闻实战手册](https://news.qq.com/rain/a/20250821A09EEU00)（⚠️ 非官方）。

### 第 2 批：依赖主体（A2 完成后 1–2 周内并行推进）

#### A4. 域名 + 阿里云 ICP 备案（网站，单位性质）

- **要做什么**：以新主体做**单位性质**备案（个人备案仅限非经营性个人作品分享，商业化产品不要用个人备案）。Web PWA 域名、后端 API 域名都要覆盖。备案通过后网站底部须展示备案号并链接 <https://beian.miit.gov.cn>。
- **去哪办**：阿里云 ICP 代备案系统（服务器在阿里云即在阿里云备案）。
- **时长与费用**：免费。阿里云初审 1–2 个工作日 + 工信部短信核验（24h 内）+ 管局审核 1–20 个工作日；整体按 2–4 周预估。
- **依赖前项**：A2（营业执照）；域名已实名认证且持有者与主体一致；阿里云中国内地服务器。
- **⚠️ 前置审批注意**：备案时网站/App 名称与内容若涉「游戏/出版」，管局会要求前置审批文件（即版号相关材料）或《不涉及前置审批承诺书》。产品名称与简介措辞避免「游戏」字样可降低触发概率——这也是类目策略（决策点 D2）的一部分。
- **来源**：[阿里云官方：ICP 备案流程概述](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/icp-filing-application-overview)；[阿里云官方：备案所需资料](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/required-materials)；[阿里云官方：前置审批](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/pre-approvals)。

#### A5. 微信小程序注册 + 微信认证

- **要做什么**：以企业/个体工商户主体注册小程序并完成微信认证（个人主体无法认证，无法开通支付等商业化能力）。个体工商户认证可用「法人微信实名辅助验证」，无需对公账户。
- **去哪办**：微信公众平台 mp.weixin.qq.com。
- **时长与费用**：数个工作日。⚠️ 微信认证费用（历史上为 300 元/次）本次未在官方页面核实到现行标准，以认证页面实际展示为准。
- **依赖前项**：A2。
- **来源**：[微信官方：虚拟支付开通条件（要求已认证的企业/事业单位/个体工商户）](https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/business-capabilities/virtual-payment.html)。

#### A6. 阿里云百炼企业账号 + 备案证明材料

- **要做什么**：将百炼/通义万相的调用切到与新主体一致的阿里云企业实名账号下；从阿里云获取两份关键材料：① 技术主体《互联网信息服务算法备案》截图（万相图像生成：达摩院图像合成算法，备案号「网信算备330110507206401230027号」；万相大模型备案号「Shanghai-TongYiWanXiang-202410090024」）；② 你的主体与阿里云主体的**合作协议**（需含算法名称/应用产品/备案编号，联系商务经理或提工单获取）。这两份材料是微信深度合成类目（A9）、安卓商店 AIGC 资质、大模型登记（A10）的通用输入。
- **去哪办**：阿里云百炼控制台 + 阿里云工单/商务；备案号可在 <https://beian.cac.gov.cn> 实时核验。
- **时长与费用**：材料获取数个工作日；无额外费用（模型调用费另计）。
- **依赖前项**：A2（企业实名）。
- **来源**：[阿里云官方：百炼模型备案信息公示](https://help.aliyun.com/zh/model-studio/model-filing-information-publicity)；[阿里云官方：千问/万相应用上架合规操作](https://help.aliyun.com/zh/model-studio/compliance-and-launch-filing-guide-for-ai-apps-powered-by-the-tongyi-model)。

### 第 3 批：依赖备案与认证（上线前 1–2 个月）

#### A7. App 备案 + 小程序备案（工信部）

- **要做什么**：2023 年起全量 App 与小程序都须向省通信管理局履行 ICP 备案。iOS/Android App 通过接入商（服务器在阿里云则经阿里云）备案；微信小程序在微信公众平台内走「小程序备案」入口。已完成网站备案的主体只需补充 App/小程序信息，不用重复提交主体材料。未备案的 App 苹果/安卓商店不予上架，小程序无法发布。
- **去哪办**：阿里云 ICP 代备案系统（App）；微信公众平台（小程序）。
- **时长与费用**：免费；平台初审 1–2 个工作日 + 12381 短信核验（24h）+ 管局 1–20 个工作日。
- **依赖前项**：A4（主体备案在先最省事）、A5。
- **⚠️ 游戏前置审批**：小程序备案若类目为游戏，需按国家新闻出版署要求提供版号材料——这是「非游戏类目」策略必须在备案环节就贯彻的原因。
- **来源**：[工信部官方：开展移动互联网应用程序备案工作的通知（工信部信管〔2023〕105号）](https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2023/art_920db564162e4312916a01bed6540ad8.html)；[微信官方：小程序备案操作指引](https://developers.weixin.qq.com/miniprogram/product/record/guidelines.html)；[微信官方：前置审批类别及审批部门](https://developers.weixin.qq.com/miniprogram/product/record/record_pre_approval.html)。

#### A8. 微信支付商户号 + 小程序虚拟支付

- **要做什么**：① 开通微信支付商户号（个体户材料：营业执照 + 经营者身份证 + 银行账户，支持法人对私账户，法人扫码验证）；② **单独开通「虚拟支付」专用商户号**——AI 生成次数、虚拟货币礼包、解锁功能等虚拟商品在小程序内（含 iOS 端）**必须**走虚拟支付，不得用普通支付或引导外部支付。⚠️ 第三方信息：2026-02-27 微信公告自 2026-04-01 起虚拟商品交易全终端强制接入虚拟支付，iOS 费率优惠期 12%、安卓约 1%，且虚拟支付仅支持对公结算——费率与结算要求请以微信公众平台「虚拟支付」模块实际展示为准。
- **去哪办**：微信支付商户平台 pay.weixin.qq.com；虚拟支付在 mp.weixin.qq.com 左栏「虚拟支付」模块开通。
- **时长与费用**：商户号审核 1–2 个工作日；虚拟支付协议签署 + 审核 1–7 个工作日 + 签约 1–2 个工作日。申请免费；交易费率普通支付 0.6% 起，虚拟支付费率以官方页面为准。
- **依赖前项**：A5（已认证小程序）、A2。
- **来源**：[微信官方：虚拟支付文档](https://developers.weixin.qq.com/miniprogram/dev/platform-capabilities/business-capabilities/virtual-payment.html)；[微信支付官方：小程序接入指引](https://pay.weixin.qq.com/static/applyment_guide/applyment_detail_miniapp.shtml)；2026-04-01 全终端新政为第三方转述（⚠️ [OSCHINA](https://my.oschina.net/u/9753123/blog/19642947)，以微信官方公告为准）。

#### A9. 微信小程序「深度合成」类目资质

- **要做什么**：AI 猫咪形象生成功能要求小程序添加「深度合成-AI绘画」（或 AI 创作）类目，提交：① 阿里云的算法备案截图；② 与阿里云的合作协议（A6 产出）。协议中的算法名称必须与备案系统完全一致，否则驳回（常见坑）。**该类目仅向非个人主体开放**。⚠️ 个体工商户是否被微信按「非个人主体」放行深度合成类目，官方文档未明确写出，需在后台实测；若被拒，此项将成为「必须用公司主体」的又一理由。
- **去哪办**：微信公众平台 → 服务类目 → 深度合成 → 对应子类目。
- **时长与费用**：审核数个工作日，免费；被驳回重提较常见，预留 2–4 周。
- **依赖前项**：A5、A6。
- **来源**：[腾讯云开发官方文档：深度合成算法合作协议与类目要求](https://docs.cloudbase.net/ai/release/algorithm-filing)；[阿里云官方：应用上架合规操作](https://help.aliyun.com/zh/model-studio/compliance-and-launch-filing-guide-for-ai-apps-powered-by-the-tongyi-model)。

#### A10. 生成式 AI「大模型登记」（属地网信办）

- **要做什么**：你调用的是**已备案**大模型（通义万相），按现行监管实践属于「基于已备案模型提供服务」——无需做完整的大模型备案，但面向境内公众提供、具有舆论属性或社会动员能力的服务需向**属地（注册地）网信办**履行**登记**手续。材料通常包括：上线登记表、调用已备案模型的情况说明与合规证明（A6 材料）、产品服务协议与隐私政策、内容安全管理制度、关键词库、测试账号等。安卓商店（如小米）上架 AIGC 应用时已明确要求提供「大模型备案或登记」证明，苹果中国区也曾集中下架无资质的生成式 AI 应用。
- **去哪办**：注册地省/市网信办（各地受理方式不同，多为线下对接 + 邮件/系统提交，建议先电话咨询）。
- **时长与费用**：免费；各地周期差异大，按 1–3 个月预估。⚠️ 各地对「图像生成类小体量应用是否必须登记」执行口径不一（部分地区宽松），且「舆论属性或社会动员能力」的认定无公开量化标准——建议直接咨询属地网信办确认，勿自行豁免。
- **依赖前项**：A2、A6、A13（隐私政策与协议是申报材料）。
- **来源**：[《生成式人工智能服务管理暂行办法》全文（国务院公报）](https://www.gov.cn/zhengce/zhengceku/202307/content_6891752.htm)（第 17 条备案义务、第 9 条服务提供者责任）；登记与备案的区分为地方网信办实践：[北京市网信办受理公告（转载）](https://www.aigcdaily.cn/news/a24wcioq5u3xfqa/)（⚠️ 转载源）、[腾讯云社区：大模型登记详解](https://developer.cloud.tencent.com/article/2648295)（⚠️ 非官方）；平台侧要求佐证：[小米开发者平台：AIGC 资质要求](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=2110)、[21财经：苹果下架未备案 ChatGPT 类应用](https://m.21jingji.com/article/20230802/herald/37afec4f96019d56170767d2ccfe2259.html)。

### 第 4 批：工程与制度项（与上并行，全部为上线硬门槛）

#### A11. AI 生成内容标识（显式 + 隐式）

- **要做什么**：2025-09-01 起强制。对 AI 生成的猫咪形象图：① **显式标识**——在图片本体或交互界面添加用户可感知的「AI 生成」文字/图形提示（用户保存、分享的图上都应保留）；② **隐式标识**——在文件元数据中写入内容属性、服务提供者名称/编码、内容编号（按强制国标 GB 45438-2025 的字段与格式）。确认通义万相 API 返回的图片是否已带隐式标识；即使带，作为服务提供者你仍需保证到达用户的最终文件合规。上架安卓商店时需提交标识佐证材料与承诺函。
- **去哪办**：工程实现 + 商店审核材料。
- **时长与费用**：开发工作量，约数天。
- **依赖前项**：无（可立即开发）。
- **来源**：[《人工智能生成合成内容标识办法》全文（国务院公报）](https://www.gov.cn/zhengce/zhengceku/202503/content_7014286.htm)；[网信办发布通稿](https://www.cac.gov.cn/2025-03/14/c_1743654685899683.htm)；[GB 45438-2025 标准信息（全国标准信息公共服务平台）](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=F32EA2A561F1886CD8D606513512D547)；[小米平台标识材料要求](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=2110)。

#### A12. 内容审核与安全管理机制

- **要做什么**：作为《生成式 AI 暂行办法》定义的「服务提供者」（即使只调 API，阿里云官方文档明确责任不转移），需要：输入/输出内容审核（可选购阿里云内容安全增值服务，或用百炼自带的绿网过滤 + 自建关键词库）、违法内容停止生成/消除 + 向主管部门报告的处置流程、用户协议（明确双方权利义务）、投诉举报入口、日志留存。这些制度文件同时是 A10 登记的申报材料。
- **去哪办**：工程实现 + 制度文档。
- **时长与费用**：数天至一周；阿里云内容安全按量计费。
- **依赖前项**：无。
- **来源**：[《生成式人工智能服务管理暂行办法》第 9、14、15 条](https://www.gov.cn/zhengce/zhengceku/202307/content_6891752.htm)；[阿里云官方：开发者仍是服务提供者、需履行全部法定义务](https://help.aliyun.com/zh/model-studio/compliance-and-launch-filing-guide-for-ai-apps-powered-by-the-tongyi-model)。

#### A13. 隐私政策 + 敏感个人信息处理（用户上传猫照片）

- **要做什么**：
  - 撰写隐私政策：明确收集目的（AI 形象生成）、方式、保存期限、是否传输给第三方（阿里云百炼——需在「委托处理/共享清单」中披露）、用户删除权。App 首次启动弹窗同意，小程序在用户隐私保护指引中配置。
  - **照片按敏感个人信息从严处理**：用户上传的家庭照片可能含人脸（生物识别信息）与住址环境信息。PIPL 第 28/29 条：处理敏感个人信息需**单独同意**（独立勾选/弹窗，不得混在总协议里）+ 告知必要性与影响。落地建议：上传前单独弹窗确认 + 明确提示「请避免上传含人物面部的照片」+（可选）本地/服务端人脸检测拦截。
  - **事前个人信息保护影响评估（PIA）**：处理敏感个人信息属 PIPL 第 55 条强制评估情形，评估报告与处理记录**至少保存 3 年**（一人开发者也不豁免）。
  - 若产品功能定位演化到主动识别人脸（当前不涉及），另需遵守 2025 年施行的《人脸识别技术应用安全管理办法》（单独同意、本地存储优先、存量达 10 万人需向省级网信部门备案）。
  - 生成图片保留期限最小化：完成生成与下载后按承诺期限删除原图。
- **去哪办**：自行撰写（可参考 GB/T 35273 与主流模板）+ 工程实现。
- **时长与费用**：3–5 天。
- **依赖前项**：无；产出为 A7/A10 及商店上架的必备材料。
- **来源**：[《个人信息保护法》全文（网信办）](https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm)；[《人脸识别技术应用安全管理办法》（网信办）](https://www.cac.gov.cn/2025-03/21/c_1744174262156096.htm)；[官方答记者问（中国政府网）](https://www.gov.cn/zhengce/202503/content_7016082.htm)。

#### A14. 未成年人保护

- **要做什么**：分两种情形：
  - **非游戏定性**：《生成式 AI 暂行办法》第 10 条要求采取有效措施**防范未成年人过度依赖或沉迷** AI 服务。落地：隐私政策中的未成年人条款、不满 14 周岁个人信息按敏感信息处理（需监护人同意）、付费环节的未成年人提示与退款通道。
  - **游戏定性（走版号后）**：必须接入国家新闻出版署防沉迷实名验证系统；未成年人仅周五六日及法定节假日 20–21 时可玩（每日 1 小时）；不得向未实名用户（含游客模式）提供服务。⚠️ 实操上防沉迷实名系统的接入以版号/出版流程为前提（IAP 小游戏流程中「中宣部实名认证必须在资质审核完成之后」），无版号产品无法完成正规接入——这也是无版号游戏不能合法收费的技术性体现。充值限额规定（8–16 岁单次 ≤50 元/月 ≤200 元等）出自国新出发〔2019〕34 号文，⚠️ 本次未直接核对原文，执行时请再确认。
- **去哪办**：工程实现；防沉迷系统经出版单位/版号流程接入。
- **时长与费用**：非游戏情形数天；游戏情形随版号流程。
- **依赖前项**：非游戏情形无；游戏情形依赖 A15。
- **来源**：[国家新闻出版署：防止未成年人沉迷网络游戏的通知（国新出发〔2021〕14号）](https://www.nppa.gov.cn/xxfb/tzgs/202108/t20210830_666285.html)；[中国政府网同文](https://www.gov.cn/zhengce/zhengceku/2021-09/01/content_5634661.htm)；[《生成式 AI 暂行办法》第 10 条](https://www.gov.cn/zhengce/zhengceku/202307/content_6891752.htm)；[微信官方：IAP 游戏发布指引（实名认证时序）](https://developers.weixin.qq.com/minigame/introduction/guide/iap.html)。

### 第 5 批：条件触发项（视决策点结果启动）

#### A15. 游戏版号路线（若决策走游戏定性 + 国内 IAP）

- **要做什么**：完整链路：内资有限公司（经营范围含游戏）→ ICP 经营许可证 → 与持《网络出版服务许可证》的出版单位签约 → 出版单位代报省级出版主管部门初审 → 国家新闻出版署终审发版号 → 接入防沉迷实名系统 → 各平台（微信小游戏/苹果/安卓商店）提交版号材料。个人无法申请；软著权利人须与公司一致。2019 年起游戏类《网络文化经营许可证》（文网文）已停止核发、《网络游戏管理暂行办法》已废止，**无需也无法再办游戏文网文**（个别代办机构仍宣称需要，⚠️ 来源冲突，以官方废止文件为准）。
- **去哪办**：出版单位合作（市场上有版号代理/联合出版服务）；ICP 许可证在工信部政务平台 <https://ythzxfw.miit.gov.cn> 申报。
- **时长与费用**：ICP 许可证：公司注册资本 ≥100 万（认缴）、3 名员工社保、20–30 个工作日，代办市场价约 0.8–3 万元（⚠️ 非官方；2025 年起还需等保三级测评报告，一人公司达标有实际困难）。版号申报 4–8 个月；出版单位合作费用市场价数万元起（⚠️ 无官方定价）。合计预留 **6–12 个月、数万至十万元级预算**。
- **依赖前项**：A1（软著在公司名下）、A2（公司）、A4。
- **来源**：[国家新闻出版署：移动游戏出版服务管理规定（官方）](https://www.nppa.gov.cn/xxgk/fdzdgknr/zcfg_210/gfxwj_215/201606/t20160602_4684.html)；[文旅部废止《网络游戏管理暂行办法》决定（官方）](https://www.gov.cn/zhengce/zhengceku/2019-12/02/content_5457656.htm)；[深圳政府在线：经营网游不需文网文](https://www.sz.gov.cn/ztfw/gysy/wyw_183970/ywzsk_184570/content/post_9230695.html)；流程/费用为代办机构汇总（⚠️ 非官方）：[壹点壹线：版号前置要求](https://www.icp-1.com/zixun/13491.html)、[ICP 许可证条件](https://www.icp-1.com/zixun/16019.html)。

#### A16. 经营性 ICP 许可证（Web 端收费的定性问题）

- **要做什么**：法规层面「经营性互联网信息服务实行许可制度」，自营网站/App 向用户提供有偿服务理论上应办 ICP 经营许可证（B25）。⚠️ **来源冲突/执法差异**：阿里云官方文档将其列为「可选，向用户提供有偿信息或服务的需要申请」；实践中大量仅有 ICP 备案的小程序/App 在售虚拟商品（支付通道由微信/苹果代收）未被要求持证，但版号申报则明确要求持有 ICP 证。个体工商户**不能**申办 ICP 许可证（须企业、注册资本 ≥100 万）。
- **建议**：轻路径阶段（收入经由微信虚拟支付/苹果 IAP 代收）暂缓；若 Web 端直接向用户收款（自建支付），办证优先级提高；启动版号路线时必办。
- **来源**：[阿里云官方：经营性网站需申请 ICP 许可证（备案流程概述内）](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/icp-filing-application-overview)；条件细节为第三方汇总（⚠️ 非官方）：[壹点壹线](https://www.icp-1.com/zixun/11202.html)。

## 2. 需要你拍板的决策点

### D1. 主体形态：个体工商户 vs 一人有限公司

| | 个体工商户 | 一人有限公司 |
|---|---|---|
| 微信支付/虚拟支付 | ✅ 可开（法人对私账户可用于普通支付；虚拟支付结算要求以官方页面为准） | ✅ 可开（需对公账户） |
| ICP 单位备案 / App 备案 | ✅ | ✅ |
| 深度合成类目 | ⚠️ 需实测（文档写「非个人主体」） | ✅ |
| 版号申请 | ❌ 不可 | ✅（纯内资 + ICP 证） |
| ICP 经营许可证 | ❌ 不可 | ✅ |
| 维护成本 | 极低（可核定征收） | 代账 + 对公户 + 双重征税 |
| 责任 | 无限连带责任 | 有限责任（需财务隔离） |

**推荐**：如果接受 D4 的「短期不碰版号」结论 → **个体工商户**起步，成本和维护负担最小，覆盖除版号/ICP 证外的全部资质需求。如果你内心已确定 1 年内要做国内游戏 IAP → 直接注册**一人有限公司**，避免日后小程序主体变更、备案迁移、软著转让的折腾（每项都是数周级流程）。

### D2. 微信端类目策略：小游戏 vs 非游戏类目

- **选小游戏类目**：IAP（虚拟货币礼包）必须版号 → 触发 A15 全链路。无版号只能纯广告变现（IAA），且发布仍需软著 + 自查报告（个人主体可上免费小游戏但无法收费）。
- **选非游戏类目**（如「工具/生活服务」+「深度合成-AI绘画」）：AI 生成次数包、会员等虚拟商品可走虚拟支付合法售卖，无需版号。**风险**：旅行青蛙式的玩法（猫咪出行、收集、明信片）若被微信审核认定为游戏，会被要求改类目/驳回/下架；「虚拟货币礼包」这种强游戏化售卖形态会显著提高被认定概率。审核尺度无公开标准（⚠️ 不确定项）。
- **推荐**：走**非游戏类目**，但配套产品改造：把「虚拟货币礼包」重构为「AI 生成次数包 / 订阅会员」，界面文案避免「金币」「充值」「关卡」等游戏词汇，定位强调「AI 宠物形象生成 + 陪伴记录工具」。这是一人开发者唯一现实的国内合规变现路径；保留玩法但弱化「游戏」外观。若坚持虚拟货币体系，请按 D4 评估版号。

### D3. iOS 地区策略：中国区 vs 先海外区

- **中国区 + 游戏类目**：需版号 + 公司开发者账号（个人账号不能被版号授权）→ 短期不可行。
- **中国区 + 非游戏类目**（如 Lifestyle/Entertainment）：无需版号，但需 App 备案（A7）+ AIGC 资质（苹果对中国区生成式 AI 应用有下架先例）；同样存在被苹果审核重新归类为游戏的风险（⚠️ 不确定项）。
- **仅海外区**（美区/港台等，取消勾选中国大陆）：无需版号、无需备案，个人账号即可上架收内购；但大陆用户（大陆 Apple ID）无法下载，等于放弃国内 iOS 自然量。
- **推荐**：**双轨**——国内用户以微信小程序 + Web PWA 承接（这两端你可控性最高），iOS 首发海外区验证；待非游戏定性在微信端跑通、或版号到手后，再上中国区 iOS。

### D4. 是否启动版号

- 成本：公司 + ICP 证（含 3 人社保、等保测评——一人开发者达标困难）+ 出版单位合作数万元 + 4–8 个月申报 + 防沉迷/实名对接，合计 6–12 个月与十万元级投入，且个体开发者小体量产品过审无保障。
- 收益：国内全渠道（小游戏 IAP、中国区 App Store 游戏、安卓商店游戏）合法收费。
- **推荐**：**现阶段不申请**。用 D2 的非游戏定性 + D3 的双轨发布先验证商业模型；若 6–12 个月后 IAP 收入证明值得，再以公司主体启动版号（届时软著、备案等资产若已在公司名下可直接复用——见 D1）。

### D5. 未成年人策略（次要，但需明确）

- 非游戏定性下仍建议：注册环节年龄声明、不满 14 周岁需监护人同意（PIPL 第 31 条）、付费页未成年人提示。若未来走版号，防沉迷实名系统接入是硬性要求，需在游戏架构中预留实名/时长/消费管控模块。
- **推荐**：本期按非游戏标准做齐上述轻量措施即可，不接防沉迷系统（无版号也接不了）。
