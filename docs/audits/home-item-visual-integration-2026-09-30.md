# 首页用品与小鱼干视觉融合修复

承接 [I01–I04 交接](../handoffs/home-item-visual-integration-2026-09-30.md)。在 main 的 `c4ced87` 上推进；开工工作区干净，未改旧归档、批准母版、存档结构或产品规则。

## 根因与实际变更

| 项目 | 确认原因与处理 | 复审结论 |
| --- | --- | --- |
| I01 | 原 `.windowsill` CSS 明确绘制 92% 不透明纸白圆底、边框与浮起阴影，和透明鱼干 PNG 无关；A/B/F 原坐标均位于 gaze 猫附近。移除圆底与悬浮位移，将鱼干放在猫右侧窗台，数量提示放在窗台下；保留至少 44×44 的透明按钮、焦点轮廓与准确可访问名称。 | 猫尾、落脚和窗台接触清楚可见；17/24 条数量不改变鱼干体积或占用猫的位置。0 条隐藏，鼠标及 Enter 收取后余额正确增加。 |
| I02 | 猫窝原图 994×640，本身有织纹；缩到桌面约 102×65 后细纹不明显，底部接触很弱。保留原图与轮廓，在显示尺寸补轻微颗粒明暗，并在底部窄带补接触阴影。 | 保留浅色软垫与鼠尾草/米白/蓝灰色区别，底部承托增强。未声称重新绘制了原有几何造型。 |
| I03 | 隧道原图有细织纹与底部暗边；小尺寸下包边、圆口显得更光滑。采用同一轻颗粒处理，阴影沿隧道底部倾斜接触线压在地毯上，而非给全部轮廓添加投影。 | 洞口、悬球和包边仍可辨认；play 的猫与前景遮挡保留，F 的 rest 仍落在上层平台、play 仍在下层地毯。 |
| I04 | 原顶栏将多条鱼的复杂图案压到 20px。改为 26×24 的单鱼 SVG 轮廓，保留鱼尾、眼与鳃线。 | 实际显示尺寸下更清楚；余额文字与可访问名称不变，仍是 UI 图标。 |

用品处理属于运行时合成：SVG 滤镜只将轻微明暗颗粒乘入 RGB，颗粒 alpha 恒为 1，因此原有 base/occlusion alpha 保持；两层使用同一滤镜和同一显示框。复审中发现过遮罩切边细线，已通过取消会改变边缘 alpha 的混合方式修正。没有统一降低透明度、模糊原图、重画背景或地毯，也没有改猫位置。没有生成新位图或把新字节冒充为旧审批素材；`promote-home-release --check` 继续验证原 29 个批准资产与来源哈希。

## 证据与验证

[独立归档](../releases/archive/2026-09-30-item-integration/README.md) 保存整页、I01–I04 独立前后截图、背景单独/用品单独/实际合成，以及 A/B/F × gaze/sleep/play/eat、默认动画与 reduced-motion poster、早晨/傍晚/深夜截图。图片均实际打开复审；造型保持原素材，本次结论限定为小尺寸材质与承托融合改善，不是全面美术重制。

- 生产复现命令：`npm run test:e2e:production --workspace @bravecat/web -- --grep '鱼干.*1280'`。修改前失败：期望透明背景，实际 `rgba(250, 247, 235, 0.92)`；原图另存 `before-desktop.png`。
- 最终生产 E2E：11/11，通过原故事、离线、升级、备份与首页几何测试，并新增 1280×720、390×844、320×568 的 A/B/F × 1/17/24 条鱼干收取与无遮挡验证。收取后覆盖 0 条隐藏状态，包含鼠标、键盘和焦点。短屏滚动能到达导航，无横向溢出。
- 主题定向单元测试：28/28；`npm run check`：通过，Svelte 0 errors/0 warnings。
- `npm run build`：通过，包含原资产审批门禁、正式资源检查及 149 条离线预缓存。
- `scripts/capture-home-item-integration.mjs` 使用独立浏览器存档、生产随机选择端口及固定时间；没有使用生产禁用的 `homeActivity` URL 参数，也没有清除用户公网数据。

CI、代码 SHA、Netlify 部署与公网验证以归档中的最终发布记录为准。手机是浏览器模拟，真机安装、系统分享、完整公网离线和备份往返不在本次新增验收结论内。
