# 公网首页视觉修复验收

2026-09-30。承接 [原问题记录](web-pwa-visible-issues-2026-09-29.md) 与 [交接](../handoffs/web-pwa-visual-fixes-2026-09-29.md)，只在 main 修复；旧归档、批准母版、v5 存档和托管域名保留。

## 根因与修复

- V01/V02：生产实际选中 A（`a-clear-sage`）的 gaze。隔离 Chrome 的生产构建复现原图，场景宽 668px，猫的旧 paint bounds 底部约 y516、窗台约 y589。直接扫描正式 poster 的 alpha>32 得到脚底 y490/512（旧 bounds 为 960/1024，差异只能解释约 4px，不能解释整个空隙）。三套主题的 gaze 坐标均未贴合真实窗台。按批准 base plate 实测承托线，A/B 在设计画布 y880，F 在 y750；保持原大小与水平位置，将框顶改为 A/B y555、F y444。正式 gaze 动画 64 帧可见底部均为 y490，落点稳定。未改文案、动画或母版。
- V03：场景实际高 890.66px，但 `.room` 仍使用旧 CSS 房间的 510px 高度且 overflow:hidden。用品已加载，只是在裁切范围外。现在房间为完整 3:4 场景留出流式空间，陈列、用品、遮挡、热区和光照仍共享同一坐标系。
- V04：原卡片底部 y762 超过 720px。桌面卡片根据视口高度限制宽度，短屏压缩标题与导航留白；1280×720 下完整卡片止于 y708。390×844 正常显示完整场景；更短屏可正常滚动，不强制压缩文字或隐藏操作。
- V05：信息卡从场景右下叠层移到场景下方，居中连接小猫名字和状态，移除对花瓶与柜子的遮挡。
- V06：“布置家”从 28px 高、0.56rem 字号提升到 44px 高、0.8rem；状态文字为 0.85rem、1.5 行高。此次未宣称全面 WCAG 验收。
- V07：核对 [Netlify 官方徽章配置](https://docs.netlify.com/manage/projects/powered-by-netlify-badge/)，当前免费站点支持关闭。已在现有项目 General → Powered by Netlify badge 关闭，界面确认 “The badge is not shown on this project.”，没有升级套餐或改应用 CSS 来隐藏平台内容。公网结果随发布复核。
