# 免费 Web/PWA 实现与验收记录

日期：2026-09-29。依据 `docs/plans/web-pwa-first-release-spec.md`。本记录是新增实现的证据，不复用交接前 CI 作为故事验收；尚未正式公开发布。

## 已实现

- 两组固定四幕目录，20%/30% 概率与物品相对权重；保留真实车票命中，优先未完成、避开其他猫锁定的故事、故事后至少一次普通旅行。
- 同刻多猫按 CatId 稳定顺序规划；旅程种子、实际旅行者/名字、故事/版本、四幕完整配方与绝对时刻落盘，刷新不重抽。
- 20/40/60/80% 揭晓，100% 归家；离线补齐、尾页解锁、重复推进不重入册；故事不伪装成地标，不额外发 Treat 或纪念品，行囊沿用原结算。
- v5 契约/状态；v4 仅补故事状态，旧已规划普通旅行不改变。坏文件与未知版本导入不覆盖当前进度；早期迁移也拒绝恢复后会丢条目的损坏数据。
- 小故事相册按故事分组、保留历次旅行、顺序翻页与尾页；只渲染已抵达幕，单卡 PNG 保存/系统分享适配。故事完整画面不叠 Portrait。
- 8 张批准故事图派生为完整画面 contain WebP；A/B/F、猫窝/隧道与 Minho 动画共 29 个素材进入独立正式目录。哈希清单关联全量批准记录，未修改批准母版或归档。
- 生产 Web 固定本地存档、同源素材，不因遗留 API/CDN 环境变量启用云请求；开发适配器保留。故事规划由 Web 显式启用，尚无故事相册的其他端不新增故事出发。
- PWA precache 覆盖故事与正式家素材；当前总计 88 条，约 30.5 MiB。大于默认 2 MiB 的已批准动画使用 4 MiB 单文件上限。
- 地标 promotion 支持带指纹材料的 cleared 状态；实际历史记录仍未 cleared，未翻转其 shipping 标记。现有合成图批准取本轮全量审批的准确字节，旧 partial 文档保留。
- 可追溯候选包脚本与 CI artifact，包内包含 commit、逐文件哈希、压缩包哈希和未完成发布项；不冒充已公开发布。

## 当前本地证据

- `npm run check`：全部 workspace 通过。
- `npm test`：48 个 Vitest 文件、344 个用例；27 个脚本用例，共 371 项通过。之后的导入加固经 core 167 用例和全 workspace check 再验。
- `npm run assets:check-landmarks`：25 个目的地、61 个场景校验通过，仍非 shipping。
- `npm run build`：正式 Web 构建通过，8 张故事图与 29 个家素材的输出哈希及 SW precache 均核验；地标被正确排除。
- `npm run build:weapp --workspace @bravecat/miniprogram`：构建通过，保留既有 es2023 target 警告，不作为小程序真机证据。
- `npm run test:e2e`：6 项已有核心循环/存档/主题测试通过；素材定位器已跟随正式路径更新。
- `npm run test:e2e:production --workspace @bravecat/web`：5 项 Chromium 正式构建测试通过：390px 首幕不泄露/单卡下载/无云请求；离线重载四幕与尾页及缓存数量；主题切换与图片实际加载/重载保留；SW 脚本更新激活后离线存档保留；JSON 导出/拒绝坏文件/导入后回看。
- 已查看正式首幕、尾页与家场景截图。SW 测试验证脚本更新激活与存档保留，不声称验证任意未来不兼容版本迁移。
- 远端 CI/E2E 以本次提交的 Actions 结果为准，最终交付消息报告；CI 同时产出 `web-pwa-candidate` 与 `playwright-artifacts`。
