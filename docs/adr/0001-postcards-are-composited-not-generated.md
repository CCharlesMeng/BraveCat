# 明信片用「场景 + 形象」离线合成,不逐张 AI 生成

2026 年的显然路径是每张明信片都拿角色参考图实时 AI 生成。我们反其道:形象(Portrait)只在猫诞生时一次性生成(v1 甚至放在开发期做),明信片由预绘场景库 + 形象姿势 + 文案邮戳层在客户端合成。理由:单张边际成本为零、画风与角色一致性有保证、支持本地优先纯静态架构(运行时零图像 API 依赖)。代价是单张明信片的「独一无二感」下降,靠场景变体、旅伴、随机文案弥补。

## Consequences

- 场景库(带合成位元数据:位置/缩放/所需姿势/翻转)成为核心美术资产,新增目的地 = 加素材而非加代码。
- 每只猫的形象必须覆盖固定姿势集,场景合成位只能引用姿势集内的姿势。
