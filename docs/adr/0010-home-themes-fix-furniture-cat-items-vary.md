# 家主题固定家具，只让小猫用品变化

Home Theme 固定房间形态、表面风格、窗框、旅行陈列、柜子、地毯和植物，
不再向玩家开放逐件换家具。不同 HomeForm 的家具尺寸、透视和遮挡天然不同；
把它们做成通用可换部件会让兼容规则和装修 UI 喧宾夺主，偏离“小猫自主生活、
玩家表达关心”的核心。玩家可选择的居家内容改为 Cat Item（小猫用品），只
覆盖吃饭、睡觉、磨爪和玩耍等猫活动；每个用品 ID 在不同家主题中由主题专属
adapter 提供适配外观、落脚面、互动目标与遮挡。

## Consequences

- `HomeThemeId` 选择一套完整固定空间；切换主题不保留或迁移逐件家具选择。
- 窗框、陈列装置、柜子、地毯和植物仍可为合成与遮挡拆成内部图层，但不是
  玩家库存，也不形成外部可换件 seam。
- 存档只保存 `homeThemeId` 与按活动位置选择的 `catItemId`，不保存家具 ID。
- 首版小猫用品位置固定为 `scratch`、`feed`、`rest`、`play`；不支持自由摆放。
- 同一 Cat Item 可以跨主题保留语义，但必须为每个可上架主题提供适配 adapter；
  缺少任一主题适配时不得上架，避免运行时兼容提示。
- 旧的家具换件 UI 与 compatibility fallback 只保留为否决方案证据。
