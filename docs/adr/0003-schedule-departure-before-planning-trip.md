# 先安排出发，再生成完整旅行计划

行囊首次变为非空时只持久化出发安排；行囊保持非空时修改不会重抽时刻，清空才取消。Clock 到达该时刻后，再以安排的出发时刻为基准，原子生成并保存不可变的完整旅行计划。这样既保留小猫自主决定何时出发，也允许玩家在等待期间继续表达关心，同时避免刷新或晚些打开应用时重抽随机结果。

## Consequences

- 存档明确区分「待出发的安排」与「已经确定的旅行」。
- 完整旅行计划包含目的地、明信片时间线与内容、纪念品及行囊物品去向；生成后只按 Clock 揭晓。
- 应用在出发时没有运行也不需要后台任务；下次打开时补生成一次并立即持久化，随机源必须可注入。
