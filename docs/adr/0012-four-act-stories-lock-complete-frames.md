# 四幕故事锁定完整画面并独立入册

根据 Web/PWA 首发规格，出发规划先保留真实心愿命中，再在合格出发中选故事；故事的身份、内容版本、旅行者名字、四幕画面/文案与绝对时刻随旅行一次锁定。小辑只收已到时的幕，第四幕解锁尾页，返程记录普通旅行间隔；重复经历保留独立旅行记录。多猫按 CatId 稳定顺序规划，已锁定故事不重复分配。

扩展 ADR-0001：普通明信片继续 Scene + Portrait；批准的故事原图已经包含 Minho，采用显式 `story-frame` 配方，客户端只绘制完整画面、文案和邮戳，不另叠 Portrait。故事不伪装成真实地标，不产生地标到访或纪念品。v5 存档新增小辑与节奏记录，v4 迁移仅补初始故事状态，不重抽旧普通旅行。

首发生产 Web 构建关闭云 API，即使配置遗留的 API URL 也不启用；开发环境保留适配器用于后续集成。完整批准图以 contain 派生 WebP，不裁掉叙事主体、不重绘、不覆盖母版。
