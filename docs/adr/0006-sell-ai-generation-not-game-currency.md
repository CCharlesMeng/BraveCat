# 只卖 AI 生成服务，小鱼干不可直购

商业化 SKU 只包含两类：AI 形象生成次数包与会员权益。Treat 保持纯游戏内货币，只能通过游戏行为获得（如收取窗台积累），不设任何真钱直购入口。产品对外定性为非游戏类目。

理由是版号与类目合规约束：售卖可用真钱购买的虚拟游戏币会强化产品的「游戏」定性，而微信小游戏开内购必须版号，个人开发者无法取得；改卖 AI 生成服务次数与会员则可走非游戏类目，是一人开发者现实可行的国内合规变现路径。详见 `docs/compliance/action-plan-2026-08.md` 决策点 D2。

## Consequences

- 服务端账本的 SKU 设计围绕生成次数 entitlement 展开，不存在可购买的 Treat 余额或兑换通道。
- 商店与付费界面文案避免「金币」「充值」「礼包」等游戏化售卖表述。
- CONTEXT.md 的 Treat 词条（游戏唯一货币，窗台积累、小铺消费）与本决策一致，获取途径不因商业化改变。
- 未来若要引入可用真钱购买的货币，需先重新评估版号路径，不能只改 SKU。
